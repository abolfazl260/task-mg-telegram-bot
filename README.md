# TaskBot — ربات مدیریت تسک تلگرام

یک ربات تلگرامی ساده و کاربردی برای مدیریت کارها، جلسات و اقدامات روزمره.

---

## ✨ امکانات فعلی

- ✅ **ایجاد تسک** با عنوان، اولویت اجباری، ددلاین، دسته‌بندی و تگ
- 🎯 **اولویت‌بندی** کارها (بالا 🔴 / متوسط 🟠 / پایین 🟢)
- 📅 **تعیین زمان انجام** (فردا، ۳ روز، ۱ هفته، ۲ هفته، ۳ هفته یا تاریخ دلخواه)
- 📋 **مشاهده لیست تسک‌های فعال** با صفحه‌بندی
- ⏳ **محاسبه زمان باقی‌مانده** تا ددلاین
- 📊 **داشبورد وضعیت اولویت‌ها**
- 📥 **دانلود خروجی اکسل** از تسک‌های فعال
- 🗓️ پشتیبانی از **تاریخ شمسی (جلالی)** در گزارش‌ها
- 💾 ذخیره‌سازی ساده و سبک با فایل **CSV**
- 👥 **Guest Mode تلگرام** برای ثبت سریع تسک و ارسال گزارش مهم از هر گروه، بدون اضافه کردن بات به گروه
- 💙 **دونیت با Telegram Stars** در مبالغ ۱۰، ۴۰ و ۱۰۰ استارز
- 🌱 دستور `/habit` برای مدیریت عادت‌ها
- 🤖 دستور `/ai` برای پرسیدن سؤال فارسی درباره تسک‌ها با Groq

## 🚀 شروع سریع

### پیش‌نیازها
- Python 3.10 یا بالاتر
- یک ربات تلگرام (از [@BotFather](https://t.me/BotFather) توکن بگیرید)

### نصب

```bash
git clone https://github.com/abolfazl260/task-mg-telegram-bot.git
cd task-mg-telegram-bot
pip install -r requirements.txt
```

> **نکته:** کتابخانه `jdatetime` برای نمایش تاریخ شمسی استفاده می‌شود. در صورت نیاز آن را هم نصب کنید:
> ```bash
> pip install jdatetime
> ```

### تنظیمات

فایل `.env` را در ریشه پروژه بسازید و توکن ربات را قرار دهید:

```env
BOT_TOKEN=123456:ABC-DEF...
# اختیاری: فعال‌سازی دستیار هوشمند /ai با Groq
GROQ_API_KEY=gsk_...
GROQ_MODEL=openai/gpt-oss-20b
```

### اجرا

```bash
python main.py
```


### پلتفرم مدیریت چند ربات

این پروژه می‌تواند به جای یک ربات ثابت، چند ربات تلگرام را با یک هسته مشترک اجرا کند. برای هر ربات یک فایل پروفایل جدا در پوشه `bots/` بسازید و توکن و یوزرنیم همان ربات را فقط در `.env` نگه دارید؛ هیچ توکنی نباید داخل کد یا فایل JSON قرار بگیرد.

نمونه `.env` برای اجرای چند ربات:

```env
BOT_PROFILES=task_manager,request_workflow
BOT_TASK_MANAGER_TOKEN=123456:AAA...
BOT_TASK_MANAGER_USERNAME=TaskManagerPersian_Bot
BOT_REQUEST_WORKFLOW_TOKEN=987654:BBB...
BOT_REQUEST_WORKFLOW_USERNAME=RequestApproval_Bot
```

برای هر نام داخل `BOT_PROFILES` باید یک فایل هم‌نام در مسیر `bots/<name>.json` وجود داشته باشد. دو نمونه آماده در فایل‌های `bots/task_manager.json.example` و `bots/request_workflow.json.example` قرار دارد؛ آن‌ها را کپی کنید، پسوند `.example` را بردارید و قابلیت‌ها، منو و workflow اختصاصی ربات را تنظیم کنید.

هر پروفایل ربات می‌تواند این موارد را مستقل تعریف کند:

- نام، توضیحات، وضعیت فعال/غیرفعال و متغیرهای محیطی توکن/یوزرنیم
- قابلیت‌های فعال مانند تسک، تیم، گزارش، عادت، AI، دونیت، Guest Mode و import گروهی
- تنظیمات اختصاصی و سطح دسترسی‌ها
- برچسب‌های workflow و دکمه‌های اکشن اختصاصی
- منوی اصلی متفاوت برای journey هر ربات

اگر `BOT_PROFILES` تنظیم نشود، برنامه مثل قبل فقط با `BOT_TOKEN` و `BOT_USERNAME` یک ربات پیش‌فرض اجرا می‌کند.

### دستیار هوشمند Groq

اگر `GROQ_API_KEY` در `.env` تنظیم شده باشد، می‌توانید از دستور `/ai` برای تحلیل تسک‌های خود استفاده کنید:

```text
/ai امروز روی چه کاری تمرکز کنم؟
/ai تسک‌های عقب‌افتاده من را اولویت‌بندی کن
```

کلید API را داخل کد قرار ندهید؛ فقط آن را به‌صورت متغیر محیطی یا در فایل `.env` محلی نگه دارید. آدرس پیش‌فرض Groq روی endpoint سازگار با OpenAI یعنی `https://api.groq.com/openai/v1/responses` تنظیم شده است.

### ثبت تسک بدون جوین بات به گروه (Guest Mode)

برای اینکه کاربران بتوانند بات را در هر گروهی صدا بزنند و بدون اضافه کردن بات به گروه تسک بسازند، در BotFather Mini App گزینه **Guest Mode** را برای بات فعال کنید. بعد از فعال‌سازی، کاربر می‌تواند در گروه بنویسد:

```text
@YourBot add پیگیری قرارداد 2026-08-20 فوری
```

بات همان‌جا یک پاسخ مهمان می‌دهد و تسک را برای همان کاربر با دسته‌بندی `Guest: نام گروه` ثبت می‌کند.

برای ارسال گزارش مهم در گروه نیز می‌توانید از همان Guest Mode استفاده کنید:

```text
@YourBot گزارش مهم
@YourBot report status
```

خروجی شامل تعداد کل تسک‌ها، تسک‌های فعال، اولویت‌های بالا، موارد موعد امروز و تسک‌های عقب‌افتاده است و به‌صورت پاسخ مهمان داخل همان گروه نمایش داده می‌شود.

#### مراحل کامل فعال‌سازی و استفاده از Guest Mode در گروه‌ها

1. وارد [@BotFather](https://t.me/BotFather) شوید و ربات خود را انتخاب کنید.
2. از تنظیمات Mini App / قابلیت‌های ربات، **Guest Mode** را فعال کنید.
3. مطمئن شوید متغیر `BOT_USERNAME` در `.env` با یوزرنیم ربات شما تنظیم شده است تا مثال‌ها و لینک‌ها درست باشند.
4. ربات لازم نیست عضو گروه باشد؛ کاربر در هر گروهی نام کاربری ربات را تایپ می‌کند و سپس متن تسک یا گزارش را می‌نویسد.
5. برای ساخت تسک، الگوی `@YourBot add عنوان تسک تاریخ اولویت` را بفرستید؛ برای گزارش مهم، `@YourBot گزارش مهم` را ارسال کنید.
6. گزارش‌ها و تسک‌های ساخته‌شده به حساب همان کاربری وصل می‌شوند که ربات را در گروه صدا زده است.

### اجرای خودکار بعد از ری‌استارت سرور

برای اینکه ربات بعد از ری‌استارت شدن سرور، کرش برنامه یا قطع موقت شبکه دوباره به صورت خودکار اجرا شود، می‌توانید سرویس `systemd` آماده پروژه را نصب کنید. این روش برای سرورهای لینوکسی رایج مانند Ubuntu و Debian پیشنهاد می‌شود.

1. پروژه را روی سرور کپی کنید و در ریشه پروژه دستور زیر را اجرا کنید:

```bash
sudo ./scripts/install-systemd-service.sh
```

2. اگر فایل `.env` در مسیر نصب ساخته شد، مقدار `BOT_TOKEN` را در آن تنظیم کنید:

```bash
sudo nano /opt/task-mg-telegram-bot/.env
```

3. سرویس را اجرا کنید:

```bash
sudo systemctl start task-mg-telegram-bot
```

4. وضعیت و لاگ‌ها را بررسی کنید:

```bash
sudo systemctl status task-mg-telegram-bot
sudo journalctl -u task-mg-telegram-bot -f
```

سرویس نصب‌شده با `Restart=always` تنظیم شده است؛ بنابراین اگر برنامه متوقف شود یا سرور ری‌استارت شود، `systemd` ربات را دوباره اجرا می‌کند. برای تغییر مسیر نصب، کاربر سرویس یا نسخه پایتون می‌توانید متغیرهای زیر را قبل از اجرای اسکریپت مقداردهی کنید:

```bash
sudo INSTALL_DIR=/opt/task-mg-telegram-bot SERVICE_USER=taskbot PYTHON_BIN=python3 ./scripts/install-systemd-service.sh
```

## 📌 دستورات ربات

| دستور       | توضیح                          |
|-------------|--------------------------------|
| `/start`    | شروع ربات و نمایش منوی اصلی    |
| `/add`      | افزودن تسک جدید                |
| `/tasks`    | مشاهده لیست تسک‌های فعال       |
| `/skip`     | رد کردن فیلد اختیاری (دسته‌بندی یا تگ) |
| `/habit`    | مدیریت عادت‌ها                    |
| `/donate`   | حمایت با ۱۰، ۴۰ یا ۱۰۰ استارز    |
| `/ai`       | دستیار هوشمند تحلیل تسک‌ها با Groq |
