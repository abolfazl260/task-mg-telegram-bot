## 🎯 معرفی

TaskBot چرخه کامل مدیریت کار را داخل Telegram پوشش می‌دهد:

```text
ایجاد → اولویت → زمان انجام → دسته‌بندی → تگ → توضیحات → مسئول
                                      ↓
                               پیگیری و گزارش
                                      ↓
                           شروع → انجام / لغو
```

رابط کاربری برای کاربر نهایی فارسی است و عملیات اصلی با دکمه‌های Inline انجام می‌شود.

# 🚀 شروع سریع

## پیش‌نیازها

- Python 3.10 یا بالاتر
- یک Bot Token از Telegram
- اینترنت برای Telegram Bot API
- کلید سرویس‌های اختیاری در صورت فعال‌سازی آن‌ها

## نصب

```bash
git clone https://github.com/abolfazl260/task-mg-telegram-bot.git
cd task-mg-telegram-bot
python -m venv .venv
```

Linux/macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

Windows:

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## اجرا

```bash
python main.py
```

📊 گزارش وضعیت

# 📥 CSV و ورود گروهی

دو مسیر وجود دارد:

- ورود متنی با فرمت `TASKS`
- ارسال فایل CSV

نمونه:

```csv
title,priority,deadline,category,tags,description
پیگیری قرارداد,high,2026-08-20,فروش,"مشتری,فوری",تماس با مشتری
گزارش هفتگی,medium,2026-08-21,گزارش,داخلی,آماده‌سازی گزارش
```

فرایند:

```text
دانلود نمونه
↓
ویرایش
↓
ارسال CSV
↓
اعتبارسنجی
↓
Preview
↓
تأیید
↓
ثبت
```

نمونه Preview:

```text
📥 نتیجه بررسی فایل

تعداد ردیف‌ها: 25
✅ آماده ثبت: 23
❌ دارای خطا: 2

خط 8 → priority: مقدار «urgent» معتبر نیست
خط 17 → deadline: تاریخ نامعتبر است

آیا 23 تسک صحیح ثبت شوند؟
```

تا قبل از تأیید نهایی، تسک‌های آماده ثبت نمی‌شوند.

ستون‌ها:

| ستون | الزامی | توضیح |
|---|---|---|
| `title` | ✅ | عنوان |
| `priority` | ❌ | `high` / `medium` / `low` |
| `deadline` | ❌ | تاریخ مثل `2026-08-20` |
| `category` | ❌ | دسته‌بندی |
| `tags` | ❌ | تگ‌ها |
| `description` | ❌ | توضیحات |

# 👤 Guest Mode

Guest Mode برای ثبت سریع تسک و گرفتن گزارش از چت‌های پشتیبانی‌شده Telegram طراحی شده است، بدون اینکه جریان معمول پیام‌رسانی بات در آن چت لازم باشد. پیاده‌سازی فعلی payload مربوط به `guest_message` را می‌خواند و پاسخ را با `answerGuestQuery` ارسال می‌کند. fileciteturn132file0L2-L2

> استفاده واقعی از Guest Mode به پشتیبانی Telegram از Guest API و فعال‌سازی/تنظیم قابلیت در BotFather وابسته است.

## ساختار درخواست

بات اطلاعاتی مانند این موارد را از Guest payload استخراج می‌کند:

- `guest_query_id`
- کاربر ارسال‌کننده
- متن یا caption
- چت مبدأ

اگر `guest_query_id` یا شناسه کاربر وجود نداشته باشد، ثبت انجام نمی‌شود.

## مثال ۱ — ثبت ساده

```text
@YourBot add پیگیری قرارداد
```

نمونه پاسخ:

```text
✅ تسک مهمان ثبت شد

🆔 123
📌 پیگیری قرارداد
📂 Guest: نام چت
📅 بدون ددلاین
```

## مثال ۲ — ثبت با تاریخ

```text
@YourBot add پیگیری قرارداد 2026-08-20
```

تاریخ تشخیص داده شده به Deadline تبدیل می‌شود.

## مثال ۳ — اولویت بالا

```text
@YourBot add تماس فوری با مشتری 2026-08-20 فوری
```

کلمات تشخیص اولویت بالا شامل نمونه‌های زیر هستند:

```text
high
بالا
فوری
مهم
🔴
```

## مثال ۴ — اولویت متوسط

```text
@YourBot add آماده‌سازی گزارش متوسط
```

نمونه کلمات:

```text
medium
متوسط
عادی
🟠
```

## مثال ۵ — اولویت پایین

```text
@YourBot add مرتب کردن فایل‌های قدیمی پایین
```

نمونه کلمات:

```text
low
پایین
کم
🟢
```

## مثال ۶ — دستورهای مختلف

```text
@YourBot task خرید تجهیزات
```

```text
@YourBot todo پیگیری ایمیل
```

```text
@YourBot ثبت پیگیری قرارداد
```

کد Guest Mode کلمات `add`, `task`, `todo` و معادل‌های فارسی مانند `تسک`, `وظیفه`, `کار`, `ثبت`, `ایجاد` را برای استخراج عنوان می‌شناسد. fileciteturn132file0L2-L2

## مثال ۷ — گزارش مهم

اگر متن شامل «report»، «گزارش»، «status» یا «وضعیت» باشد، درخواست به گزارش تبدیل می‌شود.

```text
@YourBot گزارش مهم
```

نمونه:

```text
📊 گزارش مهم تسک‌ها

📌 کل تسک‌ها: 24
⏳ فعال: 11
🔴 اولویت بالا: 4
⏰ موعد امروز: 3
🔻 عقب‌افتاده: 2

🔥 موارد مهم:
1. پیگیری قرارداد — 2026-08-20
2. تماس با مشتری — 2026-08-12
```

## مثال ۸ — عنوان خالی

```text
@YourBot add
```

بات نباید تسک خالی بسازد و راهنمایی می‌کند:

```text
برای ثبت تسک، بات را همراه عنوان صدا بزنید؛ مثل:
@YourBot add پیگیری قرارداد 2026-08-20 فوری
```

## مثال ۹ — نام کاربر و چت

Guest Mode نام/نام خانوادگی یا username فرستنده و نام چت را برای توضیح منشأ تسک در نظر می‌گیرد؛ بنابراین یک تسک مهمان می‌تواند مشخص کند از کدام چت و توسط چه کاربری ایجاد شده است. fileciteturn132file0L2-L2

## چرخه کامل Guest Mode

```text
کاربر در چت
   ↓
@YourBot add ...
   ↓
Telegram Guest Query
   ↓
handle_guest_task
   ↓
استخراج عنوان / اولویت / تاریخ
   ↓
create_task
   ↓
answerGuestQuery
   ↓
نمایش نتیجه در همان جریان Guest
```

## محدودیت مهم

Guest Mode جایگزین کامل گروه معمولی نیست. اگر Telegram برای ربات Guest Update تولید نکند یا قابلیت مربوطه فعال نباشد، handler مربوط به Guest چیزی برای پردازش دریافت نمی‌کند.

# 🧪 عیب‌یابی

## خطای Token

بررسی:

```bash
python --version
pip install -r requirements.txt
python main.py
```

و `.env` را بررسی کنید.

## Conflict در Git

```bash
git status
```

اگر هدف فقط هماهنگ‌کردن Local با GitHub است و تغییرات Local مهم نیستند:

```bash
git fetch origin
git reset --hard origin/main
git clean -fd
```

> این دستورات تغییرات Commit نشده محلی را حذف می‌کنند.

## خطای SQLite

اگر Query خطا داد، Query را با ساختار سرویس دیتابیس هماهنگ کنید. برای داشبورد `/tasks` بهتر است از Query مستقیم `aiosqlite` و عملیات سبک `COUNT/SUM` استفاده شود و عملیات blocking در handler انجام نشود.

## `/tasks` کارت‌ها را زود نمایش می‌دهد

رفتار صحیح:

```text
/tasks
↓
Mini Dashboard + Filter Menu
↓
انتخاب کاربر
↓
دریافت و Render تسک‌ها
```

# 🧑‍💻 توسعه

تقسیم مسئولیت پیشنهادی:

```text
handlers/  → Update و تعامل با کاربر
services/  → منطق کسب‌وکار و دیتابیس
utils/     → ابزارهای عمومی و Keyboard
config.py  → تنظیمات
main.py    → ثبت Handlerها و راه‌اندازی Application
```

برای افزودن فیلتر `/tasks`:

```text
tasks_view_menu_keyboard
↓
callback
↓
query
↓
filter
↓
render
```

برای قابلیت جدید نیز ترجیحاً Handler، Service و UI از یکدیگر جدا بمانند.

# 📌 سناریوی کامل استفاده

فرض کنید کاربر مدیر تیم فروش است.

### صبح

```text
/tasks
```

```text
📊 خلاصه وضعیت شما
🔹 تسک‌های در جریان: 8
☀️ برنامه امروز: 4 تسک
🔥 عقب‌افتاده: 1 وظیفه (نیاز به پیگیری!)
```

کاربر «☀️ برنامه امروز» را انتخاب می‌کند.

### ایجاد تسک

```text
/add
```

عنوان:

```text
پیگیری قرارداد مشتری X
```

اولویت:

```text
🔴 بالا
```

ددلاین:

```text
+۲ روز
```

دسته:

```text
فروش
```

تگ:

```text
مشتری
```

توضیح:

```text
نسخه اصلاح‌شده قرارداد را ارسال و پاسخ مشتری را دریافت کن.
```

مسئول:

```text
👥 هم‌تیمی‌ها
```

سپس در طول روز وضعیت را از «در انتظار» به «در حال انجام» و در پایان به «انجام شده» تغییر می‌دهد.
