# TaskBot — ربات مدیریت وظایف در تلگرام

TaskBot یک ربات فارسی‌زبان برای مدیریت کارها، وظایف شخصی و تیمی است که به شما کمک می‌کند کارهای روزانه و پروژه‌های خود را ساده‌تر و منظم‌تر مدیریت کنید.

با TaskBot می‌توانید وظایف خود را در همان محیط تلگرام ایجاد، دسته‌بندی و پیگیری کنید و همیشه بدانید چه کارهایی در انتظار انجام هستند، چه کارهایی در حال انجام‌اند و چه کارهایی به پایان رسیده‌اند.

## ✨ امکانات

- ایجاد و مدیریت وظایف
- تعیین اولویت برای هر وظیفه
- تعیین مهلت انجام و پیگیری زمان‌بندی
- دسته‌بندی و برچسب‌گذاری وظایف
- تعیین مسئول برای وظایف و واگذاری کار به اعضای تیم
- امکان برعهده گرفتن وظایف بدون مسئول
- مدیریت وضعیت وظایف و مشاهده روند انجام آن‌ها
- ثبت توضیحات و نظر برای وظایف
- جستجو، فیلتر و مشاهده سریع وظایف
- گزارش‌های مدیریتی و آماری
- مشاهده گزارش‌ها در محیط تحت وب
- مدیریت عادت‌ها و پیگیری آن‌ها
- دستیار هوشمند برای کمک به مدیریت کارها
- اتصال به ابزارهای مدیریت کار و سرویس‌های مورد نیاز
- امکان استفاده در گروه‌ها و تیم‌ها
- امکان ایجاد و مدیریت چند ربات
- حالت اختصاصی برای کسب‌وکارها و تیم‌ها
