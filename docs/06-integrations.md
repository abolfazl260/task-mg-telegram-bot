# یکپارچه‌سازی‌ها

## دستیار هوشمند

دستور:

```text
/ai
```

نمونه:

```text
/ai امروز چه کارهای مهمی دارم؟
/ai کدام تسک‌ها عقب افتاده‌اند؟
/ai کارهای اولویت بالا را خلاصه کن
```

برای استفاده باید `GROQ_API_KEY` تنظیم شود.

## Jira

شروع اتصال:

```text
/jira
```

اطلاعات اتصال شامل آدرس Jira، هویت کاربر، API Token و Project Key است.

دستورات مرتبط:

```text
/jira_status
/jira_disconnect
```

ارتباط Task و Issue از طریق شناسه‌های داخلی و Jira Key نگهداری می‌شود و همگام‌سازی می‌تواند عنوان، توضیحات، وضعیت، اولویت و Deadline را پوشش دهد.

## Google و Microsoft

پروژه از ساختار اتصال سرویس‌های مدیریت کار خارجی پشتیبانی می‌کند. اطلاعات OAuth و اتصال در دیتابیس و بر اساس کاربر، ربات و Provider نگهداری می‌شود.

برای Providerهای OAuth، State موقت باید عمر محدود داشته باشد و پس از پایان فرآیند پاک شود.

## Telegram Business

Secretary Mode برای Telegram Business Connection طراحی شده است. تنظیم پاسخ خودکار:

```env
SECRETARY_AUTO_REPLY_ENABLED=true
SECRETARY_AUTO_REPLY_TEXT=پیام شما دریافت شد؛ به‌زودی پاسخ می‌دهیم.
```

## Telegram Stars

دونیت از مسیر Telegram Stars و چرخه پرداخت Telegram پردازش می‌شود.

مبالغ نمونه:

```text
⭐ ۱۰ استارز
⭐ ۴۰ استارز
⭐ ۱۰۰ استارز
```

## Guest Mode

Guest Mode برای دریافت درخواست‌های Guest و ایجاد تسک یا گزارش طراحی شده است. جزئیات کامل در مستندات قابلیت‌های پروژه و کد مربوط به Guest Handler قرار دارد.

محدودیت: عملکرد واقعی این قابلیت به پشتیبانی و فعال بودن API مربوطه در Telegram وابسته است.
