# Retention و Expansion — Healthcare Clinics

> وضعیت سند: Customer Growth v1  
> هدف: تبدیل استفاده اولیه از TaskMG به habit عملیاتی پایدار، renewal و expansion سالم.

---

# 1. Retention Thesis

Retention در TaskMG نباید از lock-in مصنوعی بیاید.

Retention زمانی سالم است که:

- workflowهای مهم واقعاً داخل محصول اجرا شوند؛
- manager برای visibility به آن تکیه کند؛
- frontline friction پایین باشد؛
- customer outcome ببیند؛
- replacing TaskMG operational pain را برگرداند.

---

# 2. Retention Stages

1. Activation
2. Adoption
3. Habit Formation
4. Value Realization
5. Renewal
6. Expansion

هر stage metric و owner دارد.

---

# 3. Activation

Clinic Activated اگر:

- setup complete
- target users active
- 1 workflow real
- first outcome recorded
- manager dashboard used

## Metric

Activation within onboarding target period.

---

# 4. Adoption

Adoption فقط login نیست.

## Frontline Adoption

- task created
- queue used
- outcome updated
- reminder acted on

## Manager Adoption

- dashboard views
- reassignment
- exception review
- workflow review

## Owner Adoption

- periodic review
- decision based on report

---

# 5. Adoption Metrics

- WAU by role
- workflow coverage
- tasks per active user
- outcome completion
- manager dashboard frequency
- % selected workflow inside TaskMG
- Telegram/Web mix

---

# 6. Engagement

Engagement مناسب بر role متفاوت است.

Reception:
daily.

Manager:
daily/weekly.

Owner:
weekly/monthly.

Doctor:

نباید همه roleها MAU pattern یکسان داشته باشند.

# 7. Habit Formation

Habit loop:

Trigger  
→ Task/Queue  
→ Action  
→ Outcome  
→ Next Action  
→ Manager Review

Habit زمانی شکل گرفته که customer به‌صورت طبیعی workflow را در TaskMG شروع می‌کند.

---

# 8. Habit Signals

Positive:

- users create without prompting
- old spreadsheet abandoned
- manager asks through dashboard, not chat
- workflow templates reused
- no-next-action flagged proactively

Negative:

- admin enters all tasks for everyone
- users only respond after reminder from manager
- parallel spreadsheet remains source of truth
- dashboard rarely opened

---

Customer باید value را ببیند، نه اینکه فقط استفاده کند.

## Value Metrics

- follow-up completion
- overdue trend
- time-to-action
- case without next action

- workflow cycle time

## Qualitative

- less cognitive load
- less status chasing
- clearer ownership

# 12. Retention Risk Signals

## Usage

- WAU declining
- workflow volume falling
- manager inactive

## Product

- repeated errors
- slow performance
- integration failure

## Organization

- champion left
- manager changed
- branch reorganization

## Value

- no measurable outcome
- customer sees product as duplicate entry

## Commercial

- unpaid invoices
- price complaint
- procurement change

---

# 13. Churn Risk Score

Simple model:

### Green
- healthy usage
- manager active
- outcomes visible
- support normal

### Yellow
- adoption decline
- champion weak
- unresolved requests

### Red
- no core usage
- manager inactive
- major blocker
- cancellation signal

---

# 14. Churn Intervention

## Yellow

- success review
- workflow reset
- training
- notification tuning

## Red

- executive review
- isolate critical blocker
- reduce scope
- integration solution
- commercial discussion if relevant

# 20. Expansion Thesis

Expansion باید از موفقیت core use case بیاید.

# 44. Retention Anti-Patterns

- spam notifications برای engagement
- create artificial lock-in

# 45. Definition of Healthy Customer

Customer healthy است اگر:

- frontline selected workflows را استفاده کند؛
- manager dashboard را review کند؛
- outcome data کامل باشد؛
- support issues کنترل‌شده باشد؛
- buyer بتواند value را بیان کند؛
- renewal risk پایین باشد.
